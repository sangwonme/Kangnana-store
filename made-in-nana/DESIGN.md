# 만져라! 메이드인 강나나 — 게임 기획서 v0.2

> 메이드인 와리오(특히 「만져라!」) 패러디. 몇 초짜리 마이크로게임이 쉴 새 없이 터지고, 화면에 뜬 **명령어 한 마디**만 보고 바로 해치워야 한다.
> 스타일 통일은 하지 않는다. 게임마다 실사, PS1, 귀여운 3D, 픽셀, 크레용 낙서, 점토처럼 **전부 다른 매체**를 쓰는 게 이 게임의 맛이다.

---

## 1. 한 줄

**"게임 하나 대박 나면 바나나가 평생 공짜래!" 강나나가 친구들한테 마이크로게임 30개를 하청 줬다. 플레이어는 그걸 전부 몸으로 깬다.**

- 플랫폼: 웹 (모바일 터치 우선, 마우스 겸용), `web/made-in-nana/`
- 조작: 화면 하나만 쓴다. **탭 / 연타 / 홀드 / 드래그 / 스와이프 / 원 그리기** 여섯 가지가 전부다
- 플레이 시간: 스테이지 하나에 3~5분, 전체 클리어까지 30분, 이후 무한 모드

## 2. 유머 원칙

1. **변기 유머**: 방귀, 화장실, 코딱지, 땀, 막힌 변기. 똥은 늘 "초코"나 "바나나"로 둘러대고 자막으로 시치미를 뗀다 (`※초코입니다`).
2. **어이없는 결말**: 성공해도 결과가 이상해야 한다. 뽑았더니 몸이 3미터, 벗겼더니 안에 또 탈.
3. **실패도 보상**: 실패 컷이 성공 컷보다 더 웃겨야 한다. 일부러 져보고 싶게 만든다.
4. **콜백**: 앞 게임의 결과가 다음 게임에 다시 나온다 (벗긴 껍질은 「치워라!」 바닥에, 「받아라!」에서 놓치면 「뽑아라!」 상태로 모래에 박힌다). 그리고 최종 보스는 지금까지 당한 걸 전부 기억하는 강나나다.
5. **수위**: 몸개그·방귀·변기까지만 한다. 배설물을 사실적으로 그리지 않고 성적인 묘사도 하지 않는다. 꼭지 위치 개그는 아무 일 없다는 듯 시치미 떼는 선에서 멈춘다. 등장하는 친구들 얼굴은 내부 농담이 전제이고, 본인들이 같이 웃을 수 있는 선을 지킨다.

## 3. 게임 루프

```
명령어 카드(0.6s) → 마이크로게임(기본 5s) → 결과 리액션 컷(0.8s) → 인터미션 → 다음 게임
```

| 항목 | 규칙 |
|---|---|
| 순서 | 스테이지 순서 없이 한 판이 끝없이 이어진다 |
| 출제 규칙 | **10번째마다 보스 중 하나가 랜덤**으로 나온다 (직전 보스와 같은 보스는 피함). 나머지는 일반 게임 중 랜덤 |
| 중복 방지 | 한 번 나온 일반 게임은 **최소 10판 뒤**에야 다시 나온다 (직전 10판에 나온 게임은 후보에서 제외). 일반 게임이 10종 미만이면 가장 오래전에 나온 게임을 고른다 (`src/core/schedule.js`) |
| 목숨 | 바나나 4개. 실패할 때마다 하나씩 껍질만 남는다. 보스에서 져도 1개 |
| 속도 | 시작부터 1.32배 (예전 20판째 템포). 10판 사이클 안에서 4번째, 7번째 판에 ×1.1 (「스피드 업!」), 사이클마다 +6%. 보스 뒤엔 살짝 늦춰지지만 시작 속도 밑으로는 안 내려간다. 게임 시간 = 5s ÷ 속도 (최소 2.8s) |
| 난이도 | 게임마다 L1~L3. 사이클(10판)이 지날 때마다 한 단계 오른다 (「레벨 업!」). L3 이후에는 기본 속도가 사이클마다 +10% |
| 점수 | 성공한 판 수. 최고 기록은 localStorage에 저장 |
| 연습 모드 | 타이틀의 「미니게임 목록」에서 게임 하나를 골라 반복 플레이 (목숨 무한, 3판마다 레벨 상승) |
| 인터미션 | 3D 바나나 월드: 성공하면 강나나 HAPPY(춤) → IDLE, 실패하면 SAD(비구름 아래 무릎 꿇고 좌절) → IDLE. 배너(보스 등장/스피드 업/레벨 업) → 다음 판 번호. 게임 중에는 하단 **폭탄+밧줄 타이머**와 3-2-1 카운트 |

## 7. 마이크로게임 30종

각 항목의 형식: `조작` · **규칙** (성공 / 실패) · **난이도** (L1→L3) · **연출** · **아트** · **에셋**

### STAGE 1 — 강나나 「나나의 몸뚱이」

**01 까라!** `드래그↓`
- **규칙**: 머리 꼭지에서 껍질 3갈래를 하나씩 아래로 끌어내려 벗긴다. 성공: 시간 안에 전부 벗김 / 실패: 시간 초과
- **난이도**: 갈래 3 → 4 → 벗기면 안에 탈이 한 겹 더 있음
- **연출**: 다 벗기면 흰 쫄쫄이 강나나가 수줍게 몸을 가린다. 꼭지는 그대로 붙어 있다. 실패하면 반쯤 벗겨진 채 "…추워"
- **아트**: [실사] **에셋**: ♻ `gangnana_suit.png`를 갈래별로 메쉬 워프, ✏ 같은 사진의 노란 부분을 흰색으로 칠한 쫄쫄이 버전

**02 찾아라!** `탭`
- **규칙**: 바나나 더미 속에서 진짜 강나나 얼굴이 박힌 바나나 하나를 찾는다. 가짜는 매직으로 얼굴을 낙서한 바나나와 동우 얼굴 바나나. 실패: 오답 탭 또는 시간 초과
- **난이도**: 가짜 수 늘어남 → L3에서는 바나나들이 셔플됨
- **연출**: 찾으면 "들켰다" 윙크. 오답을 누르면 그 바나나가 "누구세요?"
- **아트**: [실사] **에셋**: 📷 바나나 더미 사진 1장 (Unsplash), 강나나·동우 얼굴 누끼

**03 파라!** `드래그`
- **규칙**: 화면을 꽉 채운 콧구멍에 손가락을 넣어 휘젓고, 코딱지를 잡아 밖으로 끌어낸다
- **난이도**: 코딱지가 더 깊이 있음 → L3에서는 콧구멍이 씰룩씰룩 움직임
- **연출**: 끌려 나오는 건 만국기처럼 줄줄이 이어진 미니 바나나다. 실패하면 재채기가 터져 화면이 바나나로 범벅
- **아트**: [실사] + [낙서] 손가락 **에셋**: 📷 얼굴 클로즈업 (`_21~23`), ✏ 손가락·코딱지

**04 닦아라!** `문지르기`
- **규칙**: 탈 속에서 땀범벅이 된 얼굴을 수건으로 문질러 땀방울을 전부 닦는다
- **난이도**: 땀방울 개수 늘어남 → L3에서는 닦는 동안 땀이 다시 남
- **연출**: 땀이 노랗다 (바나나즙). 성공하면 "뽀드득" 반짝. 실패하면 땀이 얼굴 구멍에 차올라 어항처럼 찰랑거린다
- **아트**: [실사] **에셋**: ♻ `gangnana_suit.png` 얼굴 부분, ✏ 땀방울

**05 부풀려라!** `연타`
- **규칙**: 바람 빠진 강나나 인형에 펌프질을 한다. 타이머가 끝나는 순간 게이지가 적정 구간 안에 있어야 성공. 너무 많이 누르면 펑 터진다
- **난이도**: 적정 구간이 좁아짐 → L3에서는 구멍으로 바람이 샘
- **연출**: 성공하면 인형이 둥실 떠서 하늘로 사라진다 (성공 맞나?). 터지면 "뿌우우웅" 하며 방 안을 날아다닌다
- **아트**: [비닐] **에셋**: ♻ `gangnana.glb`에 부풀리기 셰이더, 🧊 펌프

**06 [BOSS] 참아라!** 약 30초
- **페이즈 1 · 대기줄**: 화장실 앞에 줄을 서 있다. 배에서 꾸르륵 파동이 오면 '조이기'를 홀드하고, 파동이 지나가면 뗀다. 너무 오래 홀드하면 피로 게이지가 찬다. 화면 옆에서는 [단면도] 장 속의 바나나들이 출구를 향해 행진한다
- **페이즈 2 · 돌진**: 칸 문이 열리면 스와이프로 달려간다. 바닥의 껍질을 피해야 한다
- **페이즈 3 · 휴지**: 앉고 보니 휴지가 없다. 옆 칸에서 칸막이 아래로 내민 손에서 휴지를 드래그해 받는다 (주는 건 가끔 바나나 껍질)
- **연출**: 클리어하면 금빛 화면에 천사 합창, 열반에 든 강나나. 실패하면 "뿌직" 소리와 함께 암전되고 자막 「잠시 후 다시 시도해 주세요」
- **아트**: [PS1] 화장실 + [단면도] **에셋**: ♻ `dongwoo_crowd`, ✏ 장 단면도, 🧊 화장실 칸, 🧊/💎 변기

### STAGE 2 — 동우 「동우의 꿈의 가게」

**07 썰어라!** `스와이프`
- **규칙**: 도마 위 바나나를 점선대로 썬다. 점선에서 벗어난 정도로 판정한다
- **난이도**: 직선 → 곡선 → L3에서는 바나나가 데굴데굴 도망감
- **연출**: 단면에 김밥처럼 작은 강나나 얼굴이 나온다. 실패하면 바나나가 "아야" 하고 반창고를 붙인다
- **아트**: [PS1] **에셋**: ♻ `kitchen.glb`, `banana.glb`, ✏ 단면 텍스처

**08 구워라!** `홀드`
- **규칙**: 토치로 바나나 브륄레를 만든다. 홀드하는 동안 익음 게이지가 오르고, 황금색 구간에서 손을 떼야 한다
- **난이도**: 구간 좁아짐 → L3에서는 바나나가 회전함
- **연출**: 너무 오래 구우면 바나나 대신 옆에 있던 강나나가 아프로 머리에 숯 얼굴이 된다
- **아트**: [PS1] **에셋**: ♻ `torch_ignite`·`sizzle_loop` 사운드, ♻ `makeBanana` (escape-gangnana `cooking.js`), 🧊 토치

**09 갈아라!** `원 그리기`
- **규칙**: 믹서 위에서 원을 그려 바나나우유를 간다. 목표 회전 수를 채우면 성공
- **난이도**: 회전 수 늘어남 → L3에서는 화살표가 정해주는 방향으로만 돌려야 함
- **연출**: 완성된 컵 위에 강나나 얼굴 라떼아트. 실패하면 뚜껑이 날아가 동우가 바나나우유를 뒤집어쓴다
- **아트**: [PS1] **에셋**: ♻ `blender.mp3`, `dongwoo.glb`, 🧊 믹서

**10 따라라!** `홀드`
- **규칙**: 소주잔에 바나나우유를 선까지 따른다. 넘치면 실패
- **난이도**: 선 높이가 랜덤 → L3에서는 잔이 테이블 위를 미끄러짐
- **연출**: 넘치면 강나나가 "아까워…" 하며 테이블에 얼굴을 묻는다
- **아트**: [실사] 술집 시리즈 사진 배경 **에셋**: 📷 `_06~_20`, ✏ 잔과 액체

**11 담가라!** `드래그↕`

## 10. 구현 메모

- **폴더 구조**: `index.html`, `src/core/`(흐름, 타이머, 입력, 판정, 인터미션), `src/games/NN_name.js`
- **마이크로게임 인터페이스**: 게임마다 `{ id, cmd, style, setup(ctx, lv), onInput(e), update(dt), teardown() }`를 내보낸다. `update`가 `'win'` 또는 `'lose'`를 반환하면 판정 끝. 시간 초과 시 기본값은 게임마다 정한다 (대부분 lose, 「지켜라!」 같은 버티기형은 win)
- **레이어**: three.js 레이어 1개와 2D canvas 레이어 1개를 겹쳐 두고, 게임마다 필요한 레이어만 켠다
- **코드 공유**: `ps1.js`와 nana-pose 모듈을 이 게임에서 쓰게 되면 그때 `shared/lib/`로 옮긴다
- **디버그**: `?game=07&lv=3`로 단일 게임을 반복 실행, `?stage=2`로 해당 스테이지부터 시작
